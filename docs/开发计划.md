## 1.0 功能（0.1.0 已做完）

- 菜单栏文字可自己配：日期、星期、农历、时间，例如「11月23日 周一 十月十五」。
- 月历：每格写农历、节气、传统节日；中国的「休」「班」角标；周末和假日日期标红。
- **三种语言**（中文 / English / 日本語），在应用里切换。切语言时主日历跟着换国家：中文→中国（农历 + 调休），English→美国假日，日本語→日本祝日（祝 角标）。
- **同事国家的假日**：主日历以外的国家，假日在日期下面画彩色小点（中国红、美国蓝、日本粉），点开这一天能看到是什么节日。
- **同事时间**：面板底部列出几个城市的当地时间、在不在上班（默认 9–18 点），周末和当地假日会标出来；城市和上班时间在设置里改。
- 日程：读 macOS 日历（iCloud、Google、Outlook 等，系统里加了的账号都能读到），列出当天日程，识别 Zoom / Meet / Teams / 腾讯会议 / 飞书等链接，显示「加入」按钮；可以快速新建日程。
- 底部倒计时：「距元旦还有 39 天」，假日当天显示「今天：国庆节」。
- 节假日提醒：前一天晚上 8 点提醒「明天要上班（调休补班）」和「明天开始放假」。
- 节假日数据每 3 天自动检查更新；设置里也能手动更新。
- 第一次从 /Applications 启动时自动打开「开机自动启动」，设置里可以关掉。

## 数据从哪来

| 内容 | 来源 | 更新 |
|---|---|---|
| 中国法定假日和调休 | github.com/NateScarlet/holiday-cn（MIT，每天抓国务院公告） | 应用内置 2025–2027，运行时从 jsDelivr 拉最新的 |
| 日本祝日（含振替休日） | 内阁府 syukujitsu.csv | 内置 2020–2027，运行时从 cao.go.jp 拉 |
| 美国联邦假日 | 按 5 U.S.C. 6103 的规则算（含周末顺延） | 不用更新 |
| 农历、节气、传统节日 | 6tail/lunar-swift（MIT） | 跟着库升级 |

内置数据由 `Scripts/update-holidays.sh` 生成到 `Sources/CalendarCore/BundledHolidays.swift`；下载的新文件放在 `~/Library/Application Support/SecondCalendar/holidays/`。

## 模块

- `Sources/CalendarCore`（无界面，有测试）：`YMD` 日期、`HolidayStore`（三国假日 + 是否放假 + 下一个假日）、`HolidayUpdater`、`LunarDay`、`Colleague` / `City`、`MonthGrid`、`MeetingLink`。
- `Sources/SecondCalendarApp`：`MenuBarExtra` 面板（`PopoverView`）、设置窗口（`SettingsView`，自己管的 NSWindow）、`EventsModel`（EventKit）、`Reminders`、`L10n`（三种语言的文字写在代码里，方便应用内即时切换）、`Snapshot`（把面板渲染成 PNG）。
- `Tests/CalendarCoreTests`：13 个测试（美国顺延规则、中国调休、日本振替、农历节日、同事状态、会议链接）。

## 常用命令

```bash
swift test                    # 跑测试
Scripts/install.sh            # 编译 → 用 Developer ID 签名 → 装到 /Applications → 重启应用
Scripts/snapshot.sh 2026-10-01   # 把面板（中/英/日、深色）渲染到 docs/ui/，用示例日程
Scripts/update-holidays.sh    # 更新内置节假日数据
Scripts/icon/make-icon.sh     # 重画图标
```

## 规矩

- 跟其他 Enzomac 应用一样：不链接、不抄 GPL/LGPL 代码；测试只用合成数据；截图用示例日程（`Scripts/snapshot.sh`），不出现 enzo 真实的日程。
- 配色沿用 TidyGrid 的 Theme（暖白、墨黑、向日葵黄）。

## 发布

- 官网 `enzomac.app/secondcalendar/`（英 / 中 / 日），页面在站点仓库 `tidygrid/site/src/sites/secondcalendar/`，文字在 `content/secondcalendar/i18n/`。
- 发新版：改好代码提交 → `VERSION=x.y.z Scripts/release.sh`（测试、签名、公证、appcast）→ 站点仓库 `site/deploy.sh`。更新密钥在钥匙串账户 `secondcalendar`，公钥在 `Scripts/sparkle-public-key`。
- 统计：Umami website `cc49d179-…`，应用只发 `app-first_open` 和 `app-open`（每天一次），设置 → 通用可关。
- 源码公开在 github.com/enzo-mac-app/second-calendar（MIT）。提交作者邮箱用 GitHub noreply 地址。
